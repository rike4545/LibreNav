# Security Policy

## Supported Versions

Security fixes are generally prioritized for the latest version of LibreNav on the default branch. Older deployed builds may not receive fixes.

## Reporting a Vulnerability

Please do not report exploitable vulnerabilities in public issues.

Use GitHub's **Private vulnerability reporting** feature for this repository if it is enabled. Otherwise, contact the repository owner privately through GitHub and request a secure channel. Do not include secrets, access tokens, private route histories, or sensitive personal data in a public report.

Please include:
- A concise description of the potential impact.
- Steps to reproduce or a proof of concept that does not harm users or systems.
- Affected versions, files, routes, or dependencies.
- Any suggested mitigation.

Please allow maintainers reasonable time to investigate and prepare a fix before publicly disclosing details. This policy is not a promise of a particular response time or a bug bounty.
